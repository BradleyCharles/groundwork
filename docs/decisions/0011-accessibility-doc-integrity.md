# ADR 0011: Accessibility requirements doc is copied verbatim

- **Status:** Accepted

## Decision

`template/docs/web-accessibility-requirements.md` is copied unchanged from Epiteleia. The generator never modifies it. A test compares its SHA-256 to the value below.

## Hash

```
sha256: 4e3db12dc67cb113a666b0960a39106edab0affa8e4cd256d3bf11b515d80c86
```

Changing the document requires a new ADR that supersedes this one and records the new hash.
