# groundwork-template

A starting point for new Next.js and Supabase projects: a security baseline, WCAG 2.2 AA checks, living documentation, and a coding-agent setup (`AGENTS.md`, hooks, reviewer subagents, skills).

This repository is generated by [groundwork](https://www.npmjs.com/package/create-groundwork). Do not edit it directly; changes are overwritten on the next release.

## Use it

1. Click **Use this template**, then **Create a new repository**.
2. Clone your new repository and open a terminal in it.
3. Run:

   ```
   npx create-groundwork@latest init
   ```

   It asks for the project name, package name, description, scope statement, roles, and optional modules, then fills in the placeholders and installs dependencies. Pass `--yes` to accept the defaults, or `--config answers.json` to run without prompts.

4. Review the changes and commit them yourself.

Until `init` runs, files contain `{{PLACEHOLDER}}` markers and the project will not install or build. CI is skipped on the sync commits in this repository for the same reason.

## Prefer a new directory?

```
npm create groundwork@latest my-app
```

creates a project in `my-app` with the same files, without going through a template repository.
